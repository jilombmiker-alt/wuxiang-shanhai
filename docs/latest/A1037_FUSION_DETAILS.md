# A10.37 融合详值与实际规则一致

Web候选0.38.0。修复A10.36.2实操发现的融合说明不一致，Android仍冻结A10.32.1。完整PRD未完成。

## 改动

融合详情直接读取当前携带武器的有效fusion对象，不再把配方outputs当成实际效果。显示中文武器名称；同武器多个融合页展示同一个合并值，并明确不能再次相乘。未携带、已替换或未生效时只说明未生效，不凭配方编造数值。旧单id融合对象按现有值读取，不迁移或重算存档。

- 剑胎：青锋剑气，伤害×1.6、范围×1.5、攻击间隔×0.78；近战不使用额外弹道，不把内部+2误写成多发两道剑气。
- 纸灵：追魂符，合并弹道加成+3（不是总弹数），攻击间隔×0.72。
- 剑轮：提示环绕常驻，不按攻击间隔发射；碎刃加成与总数上限分开说明。
- 普通武器详值、默认背景/功效、Shift及点击锁定详值、保存协议保持。

源码范围：共享模块只改`prototype-2d-pixel/src/codex.js`，另有生成的shared-core、GameBoot菜单版本文案及包版本。伤害、冷却计算、融合合并、领域与存档源码未变。

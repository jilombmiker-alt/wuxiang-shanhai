# 无相山海：邪潮

《无相山海：邪潮》是一款仍在开发中的离线 2D 像素肉鸽 RPG。玩家选择四名身份和战斗方式不同的英雄，在东方神怪与邪潮侵蚀的世界中探索房间、构筑武器与功法、处理事件和商店，并通过三份“命契”存档推进共享成长。

## 当前公开版本

- Web 候选版本：A10.37 / 0.38.0。
- 当前内容：四英雄、章节与无尽模式、房间路线、局内构筑、交易、事件、首领、三命契存档、共享成长、图鉴、触控与手柄输入。
- 最近改动：融合详情读取本局实际合并值，并显示中文名称、攻击方式适用性和多融合共用说明。
- 已完成：580 项原型测试、Cocos 规则和类型检查、三种屏幕尺寸下的交互检查。
- 尚未完成：完整产品 PRD、全地图自然平衡、正式美术、最新 Android 同步和物理真机验收。

## 本地体验

`web-demo/` 是静态网页构建。请在仓库根目录运行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080/web-demo/
```

不要直接双击 `index.html`，浏览器对模块和资源加载的限制可能导致空白页。

## 查看和构建源码

1. 安装 Cocos Creator 3.8.8。
2. 使用 Creator 打开 `source/`。
3. 选择 Web Desktop 目标进行构建。

源码快照不包含 Cocos Creator 引擎、Android SDK、JDK、签名材料或本机绝对工具链路径。构建成功也不能替代真实手机验收。
